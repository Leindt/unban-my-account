# Decisiones Técnicas — Unban My Account

## HTML/CSS/JS puro (sin framework)
**Motivo:** Sitio de marketing estático sin interactividad compleja; máxima velocidad de carga.
**Descartado:** React (overhead innecesario para contenido estático).

## Design system Adora (violeta)
**Motivo:** Violeta transmite confianza y profesionalidad; diferenciación visual del nicho.

## Multiidioma EN + ES
**Motivo:** Mercado objetivo internacional; `/es/` para SEO en español.
**Descartado:** i18n JS (innecesario para solo 2 idiomas en sitio estático).
