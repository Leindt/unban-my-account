# Arquitectura — Unban My Account

## Stack
- HTML5 + CSS3 + JavaScript puro (sin framework)
- Design system Adora (violeta)
- Multiidioma: `/es/` para español

## Estructura
```
index.html          # Página principal (EN)
es/                 # Versión española
about.html          # Sobre nosotros
services.html       # Servicios
how-it-works.html   # Cómo funciona
pricing.html        # Precios
faq.html            # Preguntas frecuentes
blog/               # Blog
contact.html        # Contacto
terms.html          # Términos
assets/             # CSS, JS, imágenes
_headers            # Headers HTTP
```

## Patrones
- Sitio estático multipage
- Sin framework JS
- Colores Adora: violeta como acento principal
